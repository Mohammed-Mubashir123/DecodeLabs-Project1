#  Password Strength Checker

##  Project Overview
Password Strength Checker is a Python-based cybersecurity project developed to analyze and validate password security based on modern password policies.

This project checks whether a password is:
- Weak
- Medium
- Strong

using multiple security validation techniques.

---

#  Features

✅ Password length validation  
✅ Uppercase letter detection  
✅ Lowercase letter detection  
✅ Number detection  
✅ Special character detection  
✅ Password strength classification  
✅ Security score display  
✅ Password improvement suggestions  
✅ Retry system for multiple password checks  
✅ Professional terminal output
